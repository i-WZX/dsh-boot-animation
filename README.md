# dsh-boot-animation

DeepSeek Harness (DSH) 纯净全屏启动视频动画插件。

---

## 🌟 特性

* **极致纯净全屏**：无进度条、无提示文字、无多余 UI 遮挡，纯黑底 `100vw × 100vh` 沉浸式电影级播放体验。
* **25 秒完播限制**：
  * $\le 25\text{s}$ 视频：完整播放至最后一帧后平滑淡出，绝不提前中断。
  * $> 25\text{s}$ 视频：第 25 秒自动触发平滑转场过渡进入主界面，绝不超时拖沓。
* **DSH 原生设置面板**：
  * 深度集成至 DSH 设置页面的左侧导航栏（位于「插件市场」正下方）。
  * **直达全展状态**：点击菜单直接展开全部设置，无多余折叠层。
  * 提供启动开关、交互与声音控制、淡出时长调节（1s ~ 4s）、进入方式切换（放完再淡 / 片尾交叉溶解 / 点击才进）。
* **素材池与实时预览**：
  * 支持多视频管理与勾选轮播。
  * 单独为每个视频提供**「预览」**按钮，点击即刻全屏演练真实的入场转场。
  * 内置 **Faststart 优化**：一键将 MP4 的 `moov` 索引表无损前移至文件头部，消除启动解码黑屏。
* **交互体验与降级**：
  * 优先尝试有声播放；若受 Chromium 自动播放策略限制则静音起播，点击屏幕任意位置可切换声音。
  * 支持键盘快捷键：按 `Esc` 或 `Space` 随时提前跳过动画。

## 📦 安装方式

### 方式 1：DSH 客户端内直接安装（推荐）

1. 打开 DeepSeek Harness 客户端。
2. 进入 **「插件管理」** / **「社区插件市场」**。
3. 在安装输入框中输入：
   ```text
   i-WZX/dsh-boot-animation
   ```
4. 点击安装并重启 DSH 客户端即可。

### 方式 2：DSH CLI 命令行安装

```bash
# 线上安装
dsh plugin --profile desktop add github:i-WZX/dsh-boot-animation

# 本地开发模式链接
dsh plugin --profile desktop add "D:\EdgeDownload\else\dsh-boot-animation"
```

## 🎬 自定义视频素材

将您的视频放置到插件目录下的 `assets/videos/` 中（支持 `.mp4`, `.webm`, `.mov`, `.m4v` 格式）：
```text
assets/videos/DeepSeek.mp4
```

进入 DSH 设置 -> **「启动动画」** 页面即可看到新增素材，并可直接勾选或点击「预览」。
