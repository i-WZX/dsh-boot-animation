# DeepSeek 启动视频加载动画 (25秒时长限制重构版)

针对 DSH 启动动画视频时长的控制需求，已将导入与播放逻辑严格**更新为 25 秒限制**。

---

## 一、25 秒限制规则与执行逻辑

1. **视频时长 $\le$ 25 秒（如 15 秒、20 秒等短片）**：
   * **完整播放至最后一帧**：通过原生 `ended` 事件精准监听，不提前截断任何结尾画面。
   * 播放结束后平滑交叉淡入（Fade Out）至 DeepSeek 界面。
   
2. **视频时长 $> 25$ 秒（超长短片或导入的长视频）**：
   * **第 25 秒平滑截断进入**：在播放到第 `25s - fadeMs`（约 23.5 秒）时自动触发柔和的交叉淡出，确保在**第 25 秒整**准时、优雅地过渡进入主系统，绝不超时占用用户等待时间。

3. **双重定时器硬保障**：
   * 在 HTML5 Video `timeupdate` 心跳监听中动态更新实时时间戳（如 `00:15 / 00:25`）。
   * 内部设置了 `maxDurationTimer` 兜底硬定时器，防止流媒体丢帧导致时间卡死。

4. **超时与卡顿容错联动**：
   * 兜底超时预算 `HOLD_BUDGET_MS` 自动与 25 秒对齐设为 30 秒（25 秒播放 + 5 秒缓冲容错）。
   * 支持用户随时按 `Esc` 或 `Space` 键即刻跳过。

---

## 二、配置项说明

在注入的配置对象 `globalThis.__DSH_BOOT_ANIM_CFG__` 或 DSH `Config` 中生效：

| 配置键名 | 默认值 | 说明 |
|---|---|---|
| `maxDurationMs` | `25000` | **视频播放时间上限（毫秒）**。严格限制为 25 秒 |
| `enterMode` | `'end'` | 进入方式。`end` 模式下 $\le$ 25s 完播，$> 25s$ 在 25s 截断 |
| `fadeMs` | `1500` | 淡入淡出过渡时长 (ms) |
| `sound` | `true` | 是否启用声音（支持浏览器自动播放策略安全降级） |
| `holdMs` | `30000` | 兜底安全预算上限 (ms) |
